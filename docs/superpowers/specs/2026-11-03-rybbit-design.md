Proxy the frontend and API behind one local origin with Caddy.

Seed the existing 4,000 synthetic users and 120-day events into Rybbit's own schema. Add clearly documented synthetic checkout page visits/checkout-start events to make same-session purchasing observable. Provision a private demo site and saved registration/purchase session funnels. Historical synthetic events may be seeded directly into the application-owned demo database, which is explicitly documented; real integration uses Rybbit's tracker/API. Repeated initialization must preserve credentials and avoid duplicate events/sites/funnels. Credentials and generated manifests remain ignored. Verify health/login, data totals, native event/funnel/retention/user APIs and browser rendering; run the existing BI checks as regression coverage.
